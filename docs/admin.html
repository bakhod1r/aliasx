Services (systemd)

NameRunsWhat it does
enabledsystemctl list-unit-files --state=enabledservices that start at bootneeds systemctl
svc NAMEstatus and last 20 log lines of a service
example
$ svc nginx
● nginx.service - A high performance web server
     Active: active (running) since Thu 2026-10-01 08:00:12 UTC; 1 day ago
   Main PID: 812 (nginx)
needs systemctl
svcr NAMErestart a service after y/N
example
$ svcr nginx
Restart nginx? [y/N] y
needs systemctl
svcstop NAMEstop a service after y/N
example
$ svcstop nginx
Stop nginx? [y/N] n
Cancelled.
needs systemctl
