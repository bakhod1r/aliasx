aliasx

Safe, modular shell aliases for bash and zsh on Linux and macOS. 468 aliases and functions in 24 modules.

Install

git clone https://github.com/bakhod1r/aliasx ~/.aliasx
~/.aliasx/install.sh

install.sh adds one line to ~/.bashrc and ~/.zshrc. Running it again changes nothing. Open a new shell.

oh-my-zsh: clone into $ZSH_CUSTOM/plugins/aliasx and add aliasx to plugins=(...).

Configure

export ALIASX_DISABLE="docker k8s"      # skip default modules
export ALIASX_ENABLE="modern dangerous"  # load opt-in modules

Set these before the aliasx line in your rc file.

Inspect

aliasx modules          # list modules
aliasx list git         # aliases in one module
aliasx check gs k tf    # is a name taken?
aliasx why lni          # lni → ln -i · link, ask before overwriting

Hints

Type an aliasx name and press Space: zsh shows what it does under the prompt.

$ lni █
lni → ln -i · link, ask before overwriting

Don't know the name? Type a word like port and press Space: related commands are listed.

$ port █
related commands:
ports [PORT] · listening TCP ports, or who listens on PORT
freeport PORT · kill what listens on PORT after y/N
waitport HOST PORT [SEC] · wait until PORT accepts connections

Same in any shell: aliasx find port. Turn lists off with ALIASX_FIND=0.

bash 4+ prints the hint above the prompt. bash 3 (macOS default) has no live hook; use aliasx why.

Safe mode

aliasx mode safe     # rm lists targets and asks [Y/n]
aliasx mode normal   # plain rm
aliasx mode          # show current mode
export ALIASX_MODE=safe   # keep it on (put in rc before aliasx)

Rules

  • Tool modules load only when the tool is installed (has docker, has kubectl…).
  • Standard commands (cp, mv, rm, cat, top, ping) are never replaced by default. Safe variants get new names: cpi, mvi, rmi.
  • Destructive actions show what they will touch and ask first. Bulk deletes live in the opt-in dangerous module and need a typed phrase.
  • No implicit sudo outside package and power commands. No -y on upgrades.
  • One meaning per name: h is history, Helm uses hm; Rust uses cargo-*; pnpm uses pn*.
