Edit text

NameRunsWhat it does
prepend FILE [TEXT]add TEXT (or stdin) as first line(s) of FILE
example
$ prepend run.sh '#!/bin/sh'
(first line of run.sh is now #!/bin/sh)
append FILE [TEXT]add TEXT (or stdin) as last line(s) of FILE
example
$ append .gitignore node_modules
(last line of .gitignore is now node_modules)

NameRunsWhat it does
grepgrep --color=autogrep with colors

countfilesfind . -type f | wc -lcount files below here
countdirsfind . -type d | wc -lcount folders below here
emptydirsfind . -type d -emptyfind empty folders
emptyfilesfind . -type f -emptyfind empty files
ff PATTERNfind files whose name contains PATTERN
example
$ ff config
./app/config.yaml
./docs/config.md
ftext TEXTfind TEXT in files below here (skips .git, node_modules)
example
$ ftext TODO

fdir PATTERNfind directories whose name contains PATTERN
example
$ fdir test
