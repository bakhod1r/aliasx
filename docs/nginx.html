nginx

nginx: test, reload, logs. Config is always tested before reload/restart.

File aliases/nginx.sh. Disable: export ALIASX_DISABLE="nginx"

Config

NameRunsWhat it does
ngtasroot nginx -ttest config
ngconfasroot nginx -Tprint full loaded config
ngvnginx -Vversion and build options
ngsitesls -l /etc/nginx/sites-enabled /etc/nginx/conf.d 2>/dev/nullenabled sites
ngrtest config, then reload if OK
example
$ ngr
nginx: the configuration file /etc/nginx/nginx.conf syntax is ok
nginx: configuration file /etc/nginx/nginx.conf test is successful
ngrestarttest config, then restart if OK
example
$ ngrestart
nginx: configuration file /etc/nginx/nginx.conf test is successful
ngsservice status
example
$ ngs
● nginx.service - A high performance web server
     Active: active (running)
