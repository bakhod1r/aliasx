Core

Core: helpers, terminal and the aliasx command. Always loaded.

General

NameRunsWhat it does
has CMDtrue when CMD is installed
example
$ has docker && echo yes
yes
aliasx_hint NAMEone-line explanation of an aliasx alias or function
example
$ aliasx_hint gs
gs → git status --short --branch · short status with branch
aliasx_find WORDloaded aliasx commands whose name or description mentions WORD
example
$ aliasx_find port
ports [PORT] · listening TCP ports, or who listens on PORT
freeport PORT · kill what listens on PORT after y/N

Terminal

NameRunsWhat it does
cclearclear screen
nowdate "+%Y-%m-%d %H:%M:%S"current date and time
weekdate "+%V"ISO week number
pathecho "$PATH" | tr ":" "\n"PATH, one entry per line
e${EDITOR:-vi}open in your editor
envgenv | sort | grep -isearch environment variables
reloadre-read ~/.bashrc or ~/.zshrc
example
$ reload
(rc file re-read, new aliases active)
yesno PROMPTask [y/N]; true only on y/yes
example
$ yesno "Deploy?" && ./deploy.sh
Deploy? [y/N] y
