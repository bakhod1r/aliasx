Core

Core: helpers, terminal and the aliasx command. Always loaded.

General

NameRunsWhat it does
has CMDtrue when CMD is installed
example
$ has docker && echo yes
yes
aliasx_hint NAMEone-line explanation of an aliasx alias or function
example
$ aliasx_hint gs
gs → git status --short --branch · short status with branch
aliasx_find WORDloaded aliasx commands whose name or description mentions WORD
example
$ aliasx_find port
ports [PORT] · listening TCP ports, or who listens on PORT
freeport PORT · kill what listens on PORT after y/N

Your own aliases (aliasx add / rm / mine)

NameRunsWhat it does
$1$_q${3:-$2}"
_aliasx_on_path NAMEprint first program NAME found on PATH
_aliasx_topsize Nread "KB<TAB>path" lines, print N largest with human sizes.
asroot CMD...run CMD as root: sudo for normal users, directly when already root or sudo is missing
example
$ asroot apt update
Hit:1 http://archive.ubuntu.com/ubuntu noble InRelease
_aliasx_systemdtrue when systemd is the running init (not just installed, as in containers)

Terminal

NameRunsWhat it does

e${EDITOR:-vi}open in your editor

reloadre-read ~/.bashrc or ~/.zshrc

$ reload
(rc file re-read, new aliases active)
yesno PROMPTask [y/N]; true only on y/yes
example

Deploy? [y/N] y
